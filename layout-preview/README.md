# 第一阶段：整体布局预览

依据 `../doc/DESIGN.md` 制作，供页面结构、首屏比例、配色和留白验收。

直接用浏览器打开 `index.html` 即可查看；无需安装依赖或构建。HTML、CSS 和 JavaScript 均为独立静态文件。

本轮只交付整体布局稿。页内导航和公众号复制提供基本预览交互；已接入用户提供的真实二维码，保留原图，提供点击放大、Esc 关闭及微信搜索说明。完整交互验收和上线部署待布局确认后继续。现有 `personal-website` 项目未被替换。

当前验收方向：星空蓝背景。标题优先使用本机“幼圆”等圆体，取消厚重字重并放松字距；正文优先使用苹方、微软雅黑，保持小字号的可读性。未新增依赖、框架或外部字体请求。不同设备的系统字体不同，未安装圆体时会回退到系统无衬线字体。
