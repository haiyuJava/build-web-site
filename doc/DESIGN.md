# 个人网站设计与验收标准

## 1. 网站定位

- **我是谁**：我是一名外企程序员，正在探索用 AI 改善工作与生活，逐步走向自由工作的生活方式。
- **希望访客记住的标签**：积极拥抱 AI 时代新生活的探索者。
- **主要目标**：引导访客关注我的公众号「价投知行合一」。这是我的创作园地，也欢迎访客通过公众号向我提问。
- **页面形式**：中文单页网站，按“首屏 → 关于我 → 我在做什么 → 联系方式”的顺序展示。
- **表达方式**：第一人称，真诚、自然、简洁，体现正在探索的过程，不夸大成果。

## 2. 页面内容与结构

### 首屏

- 主标题：**向数字游民进化的外企程序员**。
- 简介：我是一名外企程序员，正在探索用 AI 改善工作与生活，逐步走向自由工作的生活方式。
- 主要按钮：**关注公众号**，跳转到本页公众号区域。
- 次要入口：**了解我**，跳转到“关于我”。
- 以文字和留白建立视觉重点，不依赖头像或大型背景图。
- 顶部导航提供“关于我”“我在做什么”“联系方式”三个页内入口；手机端采用简洁导航，无需复杂菜单。

### 关于我

初版使用以下文案：

> 我目前是一名外企程序员，也是一名积极拥抱 AI 时代新生活的探索者。我正在尝试把 AI 用到工作与生活中，寻找更适合自己的工作方式，逐步向数字游民的生活迈进。
>
> 公众号「价投知行合一」是我的创作园地，欢迎你来看看，也欢迎向我提问、交流。

不添加未经确认的公司名称、工作年限、居住地点或已经实现自由工作的表述。

### 我在做什么

初版展示三个探索方向，用简洁的文字区块呈现，不包装为已经完成的项目：

1. **探索 AI 的日常应用**：探索用 AI 改善工作与生活，让新的工具成为日常的助力。
2. **走向自由工作**：探索更适合自己的工作与生活方式，逐步向数字游民的方向迈进。
3. **持续创作与交流**：在公众号「价投知行合一」创作，也欢迎读者通过公众号向我提问。

后续有真实项目、文章或作品时，可以替换或补充这些内容。每项作品需提供真实标题、简短介绍和有效链接；没有链接时不显示“查看详情”等按钮。

### 联系方式 / 公众号

- 标题：**在「价投知行合一」继续交流**。
- 介绍：这是我的创作园地。欢迎关注，也欢迎通过公众号向我提问。
- 清楚显示公众号全名：**价投知行合一**。
- 提供“复制公众号名称”按钮，成功后显示“已复制，请打开微信搜索”。复制失败时显示可手动选中的名称和操作提示。
- 显示说明：“打开微信，搜索公众号「价投知行合一」即可关注。”
- 获得真实二维码后展示，支持点击放大，并提示“可截图后在微信中识别”。放大视图支持关闭按钮、点击遮罩和 Esc 关闭。
- 未提供二维码时，使用名称和搜索说明完成引导，不显示伪造二维码或空白图片。
- 暂不展示未经提供的邮箱、微信号、社交账号或在线咨询表单。

## 3. 视觉规范

### 整体风格

简洁、克制、自然。以文字和充足留白为主，色彩搭配沉稳，页面具有个人表达感。

- 不使用大面积渐变、轮播、自动播放视频或复杂装饰动画。
- 减少卡片和阴影，主要通过标题、间距和细分隔线组织内容。
- 公众号按钮是页面最明显的操作入口。

### 配色

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#FAF9F6` 暖白 |
| 内容表面 / 二维码底色 | `#FFFFFF` 白色 |
| 主标题与正文 | `#252525` 深灰 |
| 辅助文字 | `#626760` 灰绿 |
| 主色 / 链接 / 主按钮背景 | `#285A48` 墨绿 |
| 主按钮悬停背景 | `#204A3B` 深墨绿 |
| 主按钮文字 | `#FFFFFF` 白色 |
| 分隔线 | `#DEDFD8` 浅灰 |

浅灰分隔线不用于关键文字或唯一的控件边界。可操作元素需有清晰的键盘焦点样式。

### 字体与排版

- 使用系统字体，不依赖外部字体服务。
- 字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 标题使用同一字体族，通过字号和字重建立层级。
- 首屏标题建议采用 `clamp(2rem, 5vw, 3.5rem)`，允许自然换行。
- 正文建议 `16–18px`，行高 `1.7–1.8`；辅助说明不小于 `14px`。
- 长段落宽度控制在约 `40em` 内，避免电脑端一行文字过长。

### 布局与适配

- 主内容最大宽度约 `1080px`，居中显示。
- 手机左右留白至少 `20px`，桌面至少 `32px`。
- 手机采用单列布局；桌面的探索方向可采用三列布局。
- 手机板块上下间距建议 `48–64px`，桌面 `80–96px`。
- 按钮和主要可点击元素的触控区域至少 `44 × 44px`。
- 首屏不强制固定高度，确保小屏幕、横屏和文字放大时内容完整。

## 4. 交互与可访问性

- 导航与首屏按钮使用有效页内锚点，跳转后标题不被遮挡。
- 所有交互可用键盘操作，焦点状态清晰可见。
- 二维码弹窗打开后将焦点移入弹窗，限制焦点在弹窗内循环，关闭后返回触发按钮。
- 动效仅用于轻微颜色变化或滚动过渡；尊重 `prefers-reduced-motion` 设置。
- 采用语义化 HTML，页面仅有一个 `h1`，后续标题层级清晰。
- 图片提供合适的替代文字；二维码图片说明其用途及对应公众号名称。
- 正文与背景对比度至少达到 `4.5:1`。
- 不依靠悬停才能看到关键内容，手机端具备完整操作能力。

## 5. 技术与交付

- 使用纯 HTML、CSS、JavaScript，不使用前端框架。
- 交付可直接部署的静态文件，无需运行 `npm run build`。
- 建议文件结构：`index.html`、`styles.css`、`script.js`、`assets/`。
- 不依赖后端、数据库或登录功能。
- JavaScript 仅用于复制、二维码放大等必要交互；禁用 JavaScript 后，主要内容和页内导航仍可阅读、使用。
- 图片、样式等资源优先随网站交付，避免非必要的第三方 CDN、图标库和外部脚本。
- 图片按实际展示尺寸压缩，设置宽高以减少加载时的布局跳动；二维码保留清晰边缘和白色留白。
- 设置 `lang="zh-CN"`、UTF-8 编码和移动端 viewport。
- 默认页面标题：**AI 与自由工作探索｜价投知行合一**。
- 默认页面描述：**一名外企程序员，探索用 AI 改善工作与生活，逐步走向自由工作。欢迎关注公众号「价投知行合一」，一起交流。**
- 如已有网站使用不同技术栈，实施时需明确静态文件的部署入口；本规范不意味着现有构建或部署命令可直接沿用。

## 6. 内容与素材规则

- 不编造个人履历、项目、作品、用户评价、成果数据或联系方式。
- 不根据公众号名称推断其具体内容，不添加未经确认的投资成绩或专业身份。
- 没有素材时优先使用完整的文字布局，不用虚构图片或无效链接凑齐版面。
- 待补充信息只记录在设计文档中，不在正式页面显示“待补充”等占位内容。

当前待补充素材：

| 内容 | 是否阻塞初版 | 缺少时如何处理 |
| --- | --- | --- |
| 名字或昵称 | 否 | 使用身份介绍和公众号名称，不另取人名 |
| 公众号真实二维码 | 否 | 提供名称、复制按钮和微信搜索说明 |
| 真实项目或文章链接 | 否 | 展示三个探索方向，不设置作品详情入口 |
| 头像或个人照片 | 否 | 使用文字首屏 |

## 7. 验收标准

- [ ] 首屏能让访客在约 3 秒内理解：我是一名外企程序员，正在探索 AI 与自由工作的生活方式。
- [ ] 全站公众号名称统一为“价投知行合一”，主要关注入口醒目且可用。
- [ ] 四个板块完整，文案符合本规范且无虚构事实。
- [ ] 在 `360px`、`390px`、`768px` 和 `1440px` 视口宽度下，无横向滚动、文字重叠或内容遮挡。
- [ ] 浏览器文字放大至 200% 后，主要内容和操作仍然可用。
- [ ] 所有导航、按钮、链接和复制功能可用；复制失败时有手动操作提示。
- [ ] 提供二维码时，真机微信能够识别，放大与关闭操作正常；未提供时，搜索公众号的引导完整。
- [ ] 键盘能够完成主要操作，焦点清晰；采用弹窗时，焦点管理和 Esc 关闭正常。
- [ ] 配色与本文色值一致，正文清晰可读，手机触控区域充足。
- [ ] 无占位文本、空图片、无效入口、资源加载失败或未处理的 JavaScript 错误。
- [ ] 页面标题、简介、语言、viewport 和图片替代文字配置完整。
- [ ] 交付文件可由静态托管服务直接提供，无需构建步骤；线上打开后资源路径正确。
